# Security policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/playcanvas/skills/security/advisories/new). Do not
open a public issue for a vulnerability that could expose local files, credentials, generated code,
or agent execution to untrusted input.

Security reports should include the affected skill or bundled script, the installed agent and
package versions, reproduction steps, impact, and any known mitigation. The current supported line
is the latest `0.x` beta release; fixes may require upgrading to the newest release.
